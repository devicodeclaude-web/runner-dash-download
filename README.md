# Runner Dash — téléchargement

Jeu de type runner (synthwave) : mode Aventure (carte de niveaux, étoiles, boss) + mode Infini.

## Installer sur Android
1. Sur votre téléphone, ouvrez la page **Releases** et téléchargez **RunnerDash.apk**.
2. Ouvrez le fichier téléchargé → **Installer** (autorisez « sources inconnues » si demandé).
3. Une icône *Runner Dash* apparaît : lancez-la comme une appli de store.

## Jouer sans installer (ordinateur/navigateur)
Téléchargez **RunnerDash-jeu.zip**, décompressez, puis ouvrez `jouable-web/index.html`.
